# 🎙️ PodStream

**PodStream** is a full-featured **podcast streaming platform** built with the **MERN stack** (**MongoDB**, **Express.js**, **React**, **Node.js**) — no AWS, just pure custom backend and frontend development.

---

## 🚀 What is PodStream?

PodStream lets users:

- 🔐 **Register & log in** securely
- 📤 **Upload podcasts** (with **FFmpeg** processing)
- 🎧 **Stream and watch** podcasts online
- ❤️ **Like**, **comment**, and **increase view counts**
- 💬 **Subscribe** to podcasts and interact with other users
- 📥 **Download podcasts** for offline listening

---

## ⚙️ Tech Stack

- **Frontend:** React, CSS, Redux
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Media Processing:** FFmpeg
- **Authentication:** Custom

---

## 🎯 Purpose

PodStream is a **prototype** showcasing how to build a complete podcast platform from scratch using the MERN stack — handling everything from user auth to media upload, streaming, and interactive features.

---

## 📌 Features

- User authentication and profiles
- Podcast uploading with FFmpeg processing
- Real-time view counting and likes
- Comments and subscriptions
- Offline downloads
- Fully responsive frontend
